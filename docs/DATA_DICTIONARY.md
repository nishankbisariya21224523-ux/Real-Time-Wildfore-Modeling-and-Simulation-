# Forest Fire Geospatial Data Dictionary
| Layer | Source | Spatial Resolution | Refresh Rate |
|---|---|---|---|
| Active Hotspots | NASA FIRMS (MODIS/VIIRS) | 375m - 1km | 3 hours |
| Vegetation Greenness | Sentinel-2 / Landsat NDVI | 500m grid | 5 days |
| Canopy Water Index | Sentinel-2 NDWI | 500m grid | 5 days |
| Topography | SRTM 30m DEM (Slope/Aspect) | Resampled 500m | Static |
| Weather Telemetry | ERA5 Reanalysis / Open-Meteo | Hourly | Real-time |
